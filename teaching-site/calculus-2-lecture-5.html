Learning Outcomes

By the end of this lecture, you should be able to:

  • Distinguish local extrema, absolute extrema, and saddle behavior in several variables.
  • Use the Extreme Value Theorem to decide when global maxima and minima must exist.
  • Find interior candidates with \(\nabla f=0\) and classify them with the Hessian test.
  • Handle absolute extrema on closed regions by combining interior, boundary, and corner analysis.
  • Use Lagrange multipliers for smooth equality constraints and explain the geometry behind the formula.
  • Recognize how Taylor expansion, the inverse function theorem, and the implicit function theorem support optimization methods.

This page keeps the optimization workflow visible, while the separate Lecture 6 page gives the focused Taylor, inverse-function, and implicit-function treatment. Students usually ask the same three questions in one breath: Does an extremum exist? Where are the candidates? How do we classify them?

Key distinction: existence, candidate equations, and classification are three different tasks. Mixing them up is the most common source of errors in multivariable optimization.

Local and Global Extrema

Let \(f:D\subset\mathbb{R}^2\to\mathbb{R}\).

  • \(f\) has a local maximum at \(p\in D\) if \(f(p)\ge f(x,y)\) for all nearby points in \(D\).
  • \(f\) has a local minimum at \(p\in D\) if \(f(p)\le f(x,y)\) for all nearby points in \(D\).
  • \(f\) has an absolute maximum at \(p\) if \(f(p)\ge f(x,y)\) for all \((x,y)\in D\).
  • \(f\) has an absolute minimum at \(p\) if \(f(p)\le f(x,y)\) for all \((x,y)\in D\).

Example. For \(f(x,y)=x^2+y^2\) on \(\mathbb{R}^2\), the point \((0,0)\) is both a local and an absolute minimum, but there is no absolute maximum.

If \(p=(a,b)\) is an interior point of \(D\) and \(f\) is differentiable, then any local extremum must satisfy

\[ \nabla f(a,b)=\bigl(f_x(a,b),f_y(a,b)\bigr)=(0,0). \]

This is the multivariable version of Fermat's theorem. A critical point is a point where \(\nabla f=0\) or a first partial derivative does not exist.

Pitfall

\(\nabla f=0\) gives a candidate, not a final answer. Critical points may be minima, maxima, saddles, or inconclusive without higher-order analysis.

Extreme Value Theorem and Closed Regions

If \(D\subset\mathbb{R}^2\) is closed and bounded and \(f\) is continuous on \(D\), then \(f\) attains both an absolute maximum and an absolute minimum on \(D\). This is the Extreme Value Theorem.

That theorem answers the existence question before any calculation starts. Once existence is guaranteed, we use the standard comparison workflow:

  1. Find interior critical points with \(\nabla f=0\).
  2. Reduce each smooth boundary piece to a one-variable problem.
  3. Check corner points and endpoints.
  4. Compare all candidate values.

Counterexample. On the open disk \(x^2+y^2<1\), the function \(f(x,y)=x^2+y^2\) has no absolute maximum, because values approach \(1\) but never reach it.

Worked Closed-Region Example

Consider

\[ f(x,y)=x^2+y^2-2x-4y \]

on the rectangle \(D=[0,3]\times[0,4]\).

  • Interior critical point: \(\nabla f=(2x-2,\,2y-4)\), so \((1,2)\) with value \(f(1,2)=-5\).
  • Boundary \(x=0\): \(f(0,y)=y^2-4y\), giving candidates \(y=0,2,4\) with values \(0,-4,0\).
  • Boundary \(x=3\): \(f(3,y)=y^2-4y+3\), giving values \(3,-1,3\).
  • Boundary \(y=0\) or \(y=4\): \(f(x,0)=f(x,4)=x^2-2x\), giving values \(0,-1,3\).

Comparing every candidate shows

\[ f_{\min}=-5 \text{ at } (1,2), \qquad f_{\max}=3 \text{ at } (3,0) \text{ and } (3,4). \]

Hessian Test Through Taylor Expansion

Lecture 6 explains why the second derivative test works. If \(f\in C^2\) near \(a\in\mathbb{R}^n\), then

\[ f(a+h)=f(a)+\nabla f(a)\cdot h+\frac12\,h^{\mathsf T}H_f(a)h+o(\|h\|^2), \]

where \(H_f(a)\) is the Hessian matrix.

At a critical point, the linear term disappears, so the quadratic form decides the local shape:

\[ f(a+h)-f(a)=\frac12\,h^{\mathsf T}H_f(a)h+o(\|h\|^2). \]

Two-Variable Hessian Test

For \(f(x,y)\), write

\[ A=f_{xx}(a,b), \qquad B=f_{xy}(a,b), \qquad C=f_{yy}(a,b), \qquad D=AC-B^2. \]

  • If \(D>0\) and \(A>0\), then \((a,b)\) is a strict local minimum.
  • If \(D>0\) and \(A<0\), then \((a,b)\) is a strict local maximum.
  • If \(D<0\), then \((a,b)\) is a saddle point.
  • If \(D=0\), the test is inconclusive.

Example: Classification by the Hessian

Let

\[ f(x,y)=x^3-3xy+y^3. \]

Then

\[ f_x=3x^2-3y, \qquad f_y=-3x+3y^2, \]

so the critical points satisfy \(x^2=y\) and \(y^2=x\), giving \((0,0)\) and \((1,1)\).

The second derivatives are

\[ f_{xx}=6x,\qquad f_{xy}=-3,\qquad f_{yy}=6y. \]

  • At \((0,0)\), \(D=0\cdot0-(-3)^2=-9<0\), so the point is a saddle.
  • At \((1,1)\), \(D=6\cdot6-(-3)^2=27>0\) and \(f_{xx}(1,1)=6>0\), so the point is a strict local minimum.

Taylor Viewpoint

The Hessian test is not a separate trick. It is a direct consequence of the second-order Taylor polynomial. When the quadratic part is positive definite, the graph bends upward in every direction; when it is indefinite, the graph bends up in some directions and down in others.

Constraints, Lagrange Multipliers, and Geometric Tangency

To optimize \(f(x,y)\) subject to a smooth constraint \(g(x,y)=c\), solve

\[ \nabla f=\lambda \nabla g, \qquad g(x,y)=c. \]

The geometry is simple: at a constrained extremum, every feasible motion is tangent to the constraint curve, so the first-order change in \(f\) along that tangent direction must be zero. That makes \(\nabla f\) normal to the same curve as \(\nabla g\), hence parallel.

Example: Optimizing on the Unit Circle

Let \(f(x,y)=xy\) with constraint \(x^2+y^2=1\).

\[ \nabla f=(y,x), \qquad \nabla g=(2x,2y). \]

So we solve

\[ y=2\lambda x,\qquad x=2\lambda y,\qquad x^2+y^2=1. \]

The first two equations force \(x=\pm y\).

  • If \(x=y\), then \(x=y=\pm 1/\sqrt{2}\) and \(f=1/2\).
  • If \(x=-y\), then \(f=-1/2\).

Therefore

\[ f_{\max}=\frac12, \qquad f_{\min}=-\frac12. \]

Multiple Constraints

Lecture 6 also gives the higher-dimensional version. For \(k\) smooth equality constraints

\[ g_1(x)=c_1,\quad \dots,\quad g_k(x)=c_k, \]

the condition becomes

\[ \nabla f=\lambda_1 \nabla g_1+\cdots+\lambda_k \nabla g_k. \]

That means \(\nabla f\) lies in the normal space generated by all constraint gradients.

Inverse and Implicit Function Theorems

These theorems explain when a nonlinear problem behaves like a linear one near a point.

Inverse Function Theorem

If \(F:\mathbb{R}^n\to\mathbb{R}^n\) is \(C^1\) near \(a\) and

\[ \det J_F(a)\neq 0, \]

then \(F\) is locally invertible near \(a\), and

\[ J_{F^{-1}}(F(a))=(J_F(a))^{-1}. \]

Example. For

\[ F(x,y)=\bigl(e^x\cos y,\ e^x\sin y\bigr), \]

the Jacobian determinant is \(e^{2x}>0\), so the map is locally invertible everywhere, even though it is not globally one-to-one because of the periodic variable \(y\).

Implicit Function Theorem

If \(F(x,y)\) is \(C^1\) near \((a,b)\), \(F(a,b)=0\), and \(F_y(a,b)\neq 0\), then the equation \(F(x,y)=0\) defines a unique differentiable function \(y=\varphi(x)\) near \(x=a\). The derivative is

\[ \varphi'(x)=-\frac{F_x(x,\varphi(x))}{F_y(x,\varphi(x))}. \]

This matters for optimization because a smooth constraint can often be treated locally as a graph \(y=\varphi(x)\), turning a constrained problem into a one-variable problem.

Example: Implicit Differentiation with Structure

Take

\[ F(x,y)=x^2+xy+y^2-3. \]

At \((1,1)\), \(F(1,1)=0\) and

\[ F_y(1,1)=1+2=3\neq 0, \]

so near \((1,1)\) the equation defines \(y\) as a differentiable function of \(x\). Since

\[ F_x(x,y)=2x+y,\qquad F_y(x,y)=x+2y, \]

we obtain

\[ y'(1)=-\frac{F_x(1,1)}{F_y(1,1)}=-\frac{3}{3}=-1. \]

Constraint Interpretation

Lagrange multipliers are the global geometric language. The implicit function theorem is the local parameterization language. They describe the same smooth-constraint picture from two complementary viewpoints.

Unified Problem-Solving Workflow

Problem type Main equations How to finish
Interior local extremum \(\nabla f=0\) Use Taylor or Hessian classification.
Absolute extrema on closed region Interior critical points, boundary equations, corners Compare every candidate value.
Smooth equality constraint \(\nabla f=\lambda \nabla g\) with \(g=c\) Check all candidates and compare values.
Local solution of equation \(F(x,y)=0\), \(F_y\neq 0\) Use implicit-function theorem and derivative formula.
Local invertibility of map \(\det J_F\neq 0\) Apply inverse-function theorem.

Compact student workflow.

  1. Identify the domain type: unconstrained, compact region, or smooth constraint.
  2. Write candidate equations cleanly before computing values.
  3. Use Taylor or Hessian information only for interior classification.
  4. Use boundary analysis or constraints to capture candidates that the interior test misses.
  5. State final answers with both the point and the function value.

Practice Set

  1. Find and classify all critical points of \(f(x,y)=x^4+y^4-4x^2-4y^2\).
  2. Find the absolute extrema of \(f(x,y)=x^2+y^2+2x-4y\) on the triangle with vertices \((0,0)\), \((2,0)\), and \((0,2)\).
  3. Use Lagrange multipliers to optimize \(f(x,y)=x^2+y^2\) subject to \(x+2y=6\).
  4. Find the second-order Taylor polynomial of \(f(x,y)=\ln(1+x+y)\) at \((0,0)\).
  5. Show that \(x^2+xy+y^2=3\) defines \(y\) as a function of \(x\) near \((1,1)\), then compute \(y'(1)\).
